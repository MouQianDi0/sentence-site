长难句拆解台

输入访问密码或邀请码。输对一次，30 天内不用再输。

用邀请码登录前请看

  • 一个邀请码对应一个独立账户，句库、练习记录和设置只有你自己看得到。大小写和中间的横线输不输都行。
  • 每个邀请码只能在限定数量的设备上登录（一般是 2 台）。换浏览器、清除浏览器数据或用无痕模式都算新设备，名额满了要找管理员移除旧设备。
  • AI 批改、查词和出题要用你自己的大模型 API 密钥：登录后在“设置”里填好才能用，调用费用由你的模型平台账户承担。
  • 请不要把邀请码转给别人，别人用它登录能看到你的全部记录，还会占掉你的设备名额。
  • 管理员删除邀请码后，这个账户和里面的数据会一起删除，不能恢复。
